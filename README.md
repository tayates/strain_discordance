These data and code can reproduce the analyses in https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5929224.

The main analysis and most of the sensitivity analyses can be reproduced in STATA using 'Paired cases, main analysis_final.do' 
(dataset 'Data extraction for analysis_ final_12-12-25_less high risk studies_final_annotated.xlsx').

The sensitivity analyses using all studies, including those at high risk of bias, can be reproduced in STATA using 'Funnel plot_sensitivity analysis_all studies_12-12-2025_final.do'
(dataset 'Data extraction for analysis_All_ 12-12-25_Final_annotated.xlsx').

The population attributable fractions for recent household contact can be reproduced in R using 'MOVER-R code.R'
(dataset 'MOVER-R data.csv').

The Excel sheet 'MOVER-R A & reciprocal B and B & reciprocal A.xls', kindly provided by Robert Newcombe, will calculate the population attributable fractions using the same method.
This can be used to check the output of the R code.
